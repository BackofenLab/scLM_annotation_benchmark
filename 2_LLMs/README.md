### Setup

1. On Linux machines: `curl -fsSL https://ollama.com/install.sh | sh`
2. Install Python packages: `pip install ollama`
3. Serve Ollama: `ollama serve`
4. Pull model: `ollama pull <model name>:<model version>`. Example: `ollama pull gemma3:1b`
5. Run `python src\main.py`
